# Instagram Clone — Responsive UI

This project is a **responsive Instagram UI clone** built using **Tailwind CSS**. It focuses purely on the frontend user interface, recreating the look and feel of Instagram with a clean and modern design. The website is fully responsive and adapts smoothly to different screen sizes, including **mobile, tablet, and desktop devices**. This project helped me practice responsive layouts, reusable UI components, styling, and modern frontend design using Tailwind CSS.
